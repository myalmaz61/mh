# v3.0.0 — Постоянно кошче за бележките

Новото в тази версия:

- **Бележки → Кошче**. Изтритите бележки остават след затваряне на приложението и при следващо отваряне.
- **Възстанови** връща бележката в оригиналния ѝ вид: текст, checklist отметки, закрепване и любима звезда.
- **Изтрий окончателно** за отделен запис и **Изпразни кошчето** с потвърждение.
- Без автоматично изтриване. Максимум 100 бележки в кошчето, след което ново изтриване се отказва.
- JSON Backup / Restore запазва кошчето и го показва като отделен ред при сравнение преди Restore.
- Старите JSON архиви остават съвместими; при възстановяване на стар архив текущото кошче ще бъде изчистено, защото в архива няма негови данни.
- Индексната база остава `myhub-local` версия 1; не е необходима миграция.
- Weather, Football, SportScore и всички останали инструменти са оставени без промяна.

**Внимание:** Кошчето не е онлайн архив. То също се губи при изтриване на данните на сайта от браузъра. Съхранявай отделен JSON архив на безопасно място.
