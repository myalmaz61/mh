# MyHub v2.7.0 — проверка на SportScore API

**SportScore**: https://sportscore.com/developers/api/ . Документирани са `/api/v1/fixtures/` и параметър `competition` (идентификатор на първенството), `date` (UTC дата), `limit` (до 200). Отделната страница за английската Premier League е https://sportscore.com/football/competition/england/english-premier-league/jednm9whz0ryox8/ .

Във v2.6.0 неправилно използвахме `premier-league` като идентификатор, без да сме потвърдили, че API го приема. Във v2.7.0 опитваме последователно `english-premier-league`, `jednm9whz0ryox8` и нефилтриран дневен отговор (с проверка по име и държава). **Тези алтернативи са диагностичен подход — не гарантирано решение.**

Ако SportScore API не публикува същите исторически срещи, които показва сайтът, PWA не може надеждно да ги получи без друг разрешен източник. Поради това показваме реалния HTTP резултат и броя записи, а при празен отговор даваме директна връзка към страницата. Никога не създаваме примерни мачове като реални резултати.

Източник на резултатите се обозначава с видима връзка „Powered by SportScore“. OpenLigaDB остава отделен, данните и фаворитите му не се променят.
