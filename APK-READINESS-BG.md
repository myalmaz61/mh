# MyHub — подготовка за бъдещо Android APK

План, а **не изградена APK версия**. MyHub v2.0.0 остава PWA и може да се използва напълно безплатно с Android Chrome и GitHub Pages.

## Какво може да се използва отново

- `js/` модулите, `index.html`, CSS и локалната логика могат да се адаптират за Capacitor (Android WebView).
- Няма нужда от собствен сървър или акаунт за офлайн инструменти.
- GitHub Actions може в бъдеще да компилира Android приложение без Android Studio на телефона. Това изисква Android/Java build configuration и проверка на актуалните безплатни лимити на GitHub.

## Какво няма да се прехвърли автоматично

1. **Локалните данни на PWA не са данните на APK.** Различните браузъри/контейнери имат различни storage origins. Изтегли JSON Backup от PWA и го възстанови от настройките на бъдещото APK, след като тестваме импорта там. Не деинсталирай PWA преди успешния импорт и проверка на записите в APK.
2. **Service Worker и PWA Share Target** не трябва да се приемат за съвместими с native Android по подразбиране. Share Target ще изисква Android Intent интеграция, която записва в същия Bookmarks формат. Известия и фонови аларми също са отделна задача.
3. **Външните услуги** Weather/Football/RSS изискват интернет и допълнителна проверка на условията им, ако APK се разпространява. Няма да вграждаме лични API ключове в публичния код.
4. **APK подписване и актуализации** изискват постоянен signing key, защитен извън публичното хранилище. Загубата на ключа затруднява обновяването на инсталиран APK.

## Преди да започнем APK

- Провери MyHub PWA на телефона няколко дни; увери се, че Backup/Restore и PWA Update работят.
- Тествай един JSON архив за пълно възстановяване в **отделен тестов профил**, без да рискуваш реалните данни.
- Преди native build отдели browser-only логиката от storage/share/notifications интерфейсите; използвай адаптери, без да пренаписваш основните инструменти.
- Започни с отделен експериментален APK, а не със замяна на работещата PWA.
