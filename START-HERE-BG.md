# MyHub v2.7.0 — обновяване само с Android и GitHub

## Преди обновяването

1. Отвори **MyHub v2.6.0** → Settings → **JSON Backup**.
2. Увери се, че файлът е в **Downloads**. Не изтривай старите архиви.
3. **Не деинсталирай PWA**, не използвай Clear storage / Clear site data и не заменяй репозиторито с празно.

## Обновяване (без компютър)

1. Изтегли `MyHub-v2.7.0-UPDATE-ONLY.zip` и го разархивирай чрез Files на Android.
2. Отвори съществуващия GitHub repository в Chrome. При нужда активирай **Desktop site**.
3. В ZIP има `CHANGED-FILES.txt`. За всеки файл използвай същата папка в GitHub, например `js/` или `tests/`.
4. Когато файл съществува, отвори го в GitHub, избери редактиране, **изтрий старото съдържание и постави цялото ново съдържание** от съответния файл; Commit changes. За нов файл използвай Add file → Create new file. При възможност можеш да качиш с Upload files, спазвайки папките.
5. Не изтривай останалите файлове. Не създавай двойни папки `MyHub-v2.7.0/` в корена на репозиторито.
6. Изчакай GitHub Pages да публикува commit-а, после отвори инсталирания MyHub → Settings → PWA и обновления → Провери за обновление и активирай новата версия, ако бъде предложена.
7. Потвърди **Version 2.7.0**.

## Проверка на Premier League

1. Отвори **Football → Провери резултатите от втори източник (SportScore)**.
2. Увери се, че е избрано **English Premier League**.
3. Избери **21.11.2026** (събота) или **22.11.2026** (неделя). Натисни **Обнови**.
4. Ако видиш резултати — провери дали е посочен SportScore и дали отборите/резултатите отговарят на страницата им.
5. Ако отново няма мачове, разгъни **Диагностика на заявките**. Ще видиш примерно `HTTP 200 · raw=0` (API връща празно), `parsed=0` (разчитане) или `HTTP 404` (грешен endpoint/идентификатор). Това са диагностични стойности, не примерни мачове.
6. Натисни **Отвори API отговора в Chrome**, за да видиш първия заявен отговор. Ако има грешка/JSON, можеш да изпратиш скрийншот на диагностиката и на първите редове от JSON, без лична информация.
7. Използвай линка **Отвори пълните резултати на Premier League в SportScore** като резервен вариант.

## Какво НЕ трябва да очакваш

- Директната уебстраница може да показва срещи, които **API не връща**. Това не може да се поправи само чрез промяна на PWA.
- Не е потвърден live отговор от SportScore от нашата среда. Работата на физически Android трябва да се провери.
- Ръчното обновяване има 5-минутен минимум за повторение на успешна заявка за същата дата/първенство.

## Архиви и данни

Модулът SportScore не съхранява мачовете като твои футболни данни и не заменя OpenLigaDB фаворити. `myhub-local` остава версия 1, JSON Backup е формат 1. Всички останали инструменти остават както във v2.6.0.
