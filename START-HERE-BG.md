# MyHub v1.8.0 — Стъпки за Android + GitHub

## 1. Първо защити личните данни

1. Отвори съществуващата версия **MyHub v1.7.0**.
2. Влез в **Settings / Настройки → JSON Backup → Изтегли архив**.
3. Отвори **Files → Downloads** на Android и провери дали JSON файлът съществува, не е 0 KB и има реално съдържание.
4. Ако можеш, запази второ копие на безопасно място. Не е необходимо да използваш платена облачна услуга.
5. **Не деинсталирай PWA. Не изтривай Site Data, IndexedDB или Storage на Chrome.**

## 2. Обновяване на съществуващо MyHub (v1.7.0 → v1.8.0)

1. Изтегли **`MyHub-v1.8.0-UPDATE-ONLY.zip`** и го разархивирай в Android Files.
2. Отвори същия GitHub repository за MyHub. Не създавай нов repository.
3. В архива отвори **`CHANGED-FILES.txt`** — там е точният списък на новите и променените файлове.
4. Качи ги в съответните GitHub папки. Кореновите (`sw.js`, `package.json`, `styles.css`, документация) се качват в корена; `js/...` в папката `js`; `tests/...` в папката `tests`. Файлове, които не са в списъка, остават непроменени.
5. На Android Chrome можеш да използваш **⋮ → Desktop site** в GitHub, ако бутонът **Add file → Upload files** не се вижда удобно.
6. Когато обновяваш отделен текстов файл в GitHub, замени **цялото съдържание**, не отделни редове. Качи съдържанието на ZIP, **не ZIP файла като един файл** в репото.
7. Натисни **Commit changes** и отвори досегашния адрес GitHub Pages от същата PWA икона.
8. Провери **Settings → Version 1.8.0**. Ако виждаш стара версия, отвори през Chrome с интернет и използвай **Settings → PWA и обновления → Провери за обновление**. След това използвай **Обнови**, ако се появи. Не изтривай данните.

## 3. Тест на новите функции — без да рискуваш личните данни

1. В Settings → JSON Backup намери **„Напомняне за архив“**. Пробвай 7, 14, 30 дни и „Изключено“. Избраното трябва да се запази след повторно отваряне. Изборът не изпраща известия.
2. Натисни **Restore / Възстановяване** и посочи реалния си JSON архив. Появява се сравнение по раздели: **Сега → След Restore**. Когато архивът е по-стар, могат да се покажат предупреждения за липсващи или променени записи.
3. **Не маркирай потвърждението за Restore** при този тест. Бутонът за реално възстановяване трябва да остане неактивен.
4. Натисни **Отказ**. Провери дали съществуващите бележки и задачи не са се променили.
5. Опитай отново с валидния JSON файл само за преглед. **Не натискай финалното „Замени локалните данни“** върху важните си данни, освен ако действително искаш Restore.
6. Провери Calculator, Weather (последен кеш), Notes, Tasks и Calendar; изпробвай Calculator и Notes офлайн в Airplane mode след като приложението се е заредило онлайн.

## 4. Важно за сравнението

- Броят на записите не е достатъчен. MyHub сравнява и ID-тата на бележки, задачи, събития, списъци, връзки, RSS статии и футболни първенства, плюс съдържанието при съвпадащи ID.
- Сравнението е **ориентировъчно**: други настройки, любими преобразувания, прочитни отметки, кешове и някои вложени данни също могат да бъдат заменени при Restore. Сравнението **не е Undo** и не прави автоматично отделен архив.
- Ако текущите данни са повредени и не могат да бъдат проверени, приложението може да покаже „Не мога да сравня текущите данни“. Това само по себе си не ги изтрива.
- При стари архиви липсващите модули се възстановяват с началните си стойности. Например архив от преди въвеждането на Tasks може да замени днешните Tasks с празен списък.
- Датата на последно „подготвен“ архив е **само дата на започнато изтегляне**, не доказателство за успешно сваляне от Android. Реално провери файла в Downloads.
- Напомнянето е **само вътре в Settings**. Не разчитай на него да се появява при заключен телефон или затворено приложение.

## 5. Ако има проблем

- **Виждаш v1.7.0:** провери качените файлове и дали GitHub Pages е публикувал новия Service Worker; използвай ръчна проверка за обновления. Не деинсталирай.
- **При Backup има грешка:** не изчиствай данните. Запази текста на грешката за диагностика.
- **Прегледът показва загуба на записи:** натисни Отказ и първо си направи нов архив, който действително е в Downloads.
- **Инсталираната PWA не се обновява:** отвори я онлайн и отново провери версията от Settings; не заменяй друга инсталация с нова, ако данните са само локални.

MyHub продължава да работи локално, без платен API, сървър, регистрация или Android Studio. За бъдещ APK прехвърлянето на данни ще става с JSON Export/Restore, а не с автоматична синхронизация.
