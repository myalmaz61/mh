# MyHub v1.6.0 — инструкции за Android + GitHub

## 1. Защити старите данни

1. Отвори своята инсталирана **MyHub v1.5.0**.
2. Отвори **Настройки → JSON Backup / Изтегли JSON архив**.
3. В **Files → Downloads** провери, че архивът `MyHub-backup-....json` действително е изтеглен и не е с размер 0 bytes.
4. **Не** използвай Restore за проба, не деинсталирай PWA и **не** изчиствай Chrome Site Data.

## 2. Избери правилния ZIP

- **MyHub-v1.6.0-UPDATE-ONLY.zip** — ако в GitHub вече имаш v1.5.0. Съдържа само новите и променените файлове.
- **MyHub-v1.6.0.zip** — всички файлове, само ако правиш ново хранилище или цялостно възстановяване на кода.
- **MyHub-v1.6.0-FULL-SOURCE.md** — пълно съдържание на променените файлове за ръчно копиране, без да редактираш отделни редове.

Не е необходим компютър, Android Studio или платена услуга.

## 3. Качване в GitHub от Chrome на Android

1. Изтегли **UPDATE-ONLY.zip** и го разархивирай с Android Files.
2. Отвори **github.com** в Chrome и влез в съществуващия MyHub repository. Ако менюто не се показва, включи **⋮ → Desktop site**.
3. В корена (основната папка) замени файловете от основната папка на ZIP, като `styles.css`, `sw.js`, `package.json`, `README.md`, `START-HERE-BG.md`.
4. В **`js/`** качи съответните файлове от архивната папка `js/`. Новият файл е **`tool-order-core.js`**.
5. В **`tests/`** качи файловете от архивната папка `tests/`, включително **`tool-order.test.mjs`**. Те се съхраняват в GitHub, но не се изпълняват в PWA.
6. Използвай **Add file → Upload files → Commit changes**. Ако GitHub не позволява замяна, отвори конкретния файл → **Edit (молив)** → изтрий старото му съдържание → постави **целия код** за него от FULL-SOURCE.md → Commit.
7. Запази същата структура. Не създавай случайно `js/js/`, `tests/tests/` или папка `MyHub-v1.6.0` в репото.
8. Използвай съществуващата настройка **Settings → Pages**, без промени, ако вече работи.

## 4. Провери на телефона

1. Отвори MyHub от **съществуващата PWA икона**. Ако се появи „Обнови“, натисни го, след което отвори приложението отново.
2. Провери **Настройки → Версия 1.6.0**.
3. Разгъни **Настройки → Подредба на всички инструменти**. Премести **Бележки** с ↑ над **Световен часовник**.
4. Отвори **Всички инструменти** и провери, че „Бележки“ се вижда пред „Световен часовник“.
5. Затвори и отвори MyHub. Провери, че подредбата е останала.
6. Скрий „Бележки“ от **Настройки → Скриване на инструменти** и после ги покажи отново. Инструментът трябва да се върне на същата позиция в общия списък. Не трябва да се губят лични бележки.
7. Провери, че **любимите на началния екран** са в предишния си ред и че „Последно използвани“ работи независимо.
8. В **Настройки → Подредба на всички инструменти** натисни **Върни стандартната подредба** и провери възстановяването.
9. Изпробвай Calculator, Notes, Tasks, Calendar и Bookmarks, след което пробвай „Всички инструменти“ офлайн (в самолетен режим) след успешно онлайн обновяване.
10. Изтегли **нов JSON Backup от v1.6.0** и запази и предишния архив.

## 5. Ако виждаш стара версия

- В GitHub виж дали `js/config.js` съдържа `1.6.0`, а `sw.js` — `myhub-shell-v1.6.0`.
- Провери дали `js/tool-order-core.js` е в папка `js/` и дали GitHub Pages действително го публикува (не връща 404).
- Отвори PWA онлайн и използвай бутона „Обнови“, ако се появи. Затвори и отвори приложението отново.
- Ако има грешка, изпрати ми екранна снимка. **Не деинсталирай PWA и не изтривай данните**, за да „изчистиш кеша“.

## 6. Важни ограничения

Сортирането променя само реда на инструментите, а не данните. То не е механизъм за парола или скриване на лични записи. JSON Restore заменя текущото съдържание: прави го само след като провериш архива. Реалната работа на Android Chrome трябва да се провери на телефона; локалните автоматизирани тестове не я гарантират.
