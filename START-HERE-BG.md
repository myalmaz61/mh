# MyHub v2.5.0 — обновяване от Android и GitHub

Това е обновление **от v2.4.0 към v2.5.0**. Работи само с Android телефон, Chrome и GitHub Pages. Без компютър и платен API.

## Преди качването

1. В MyHub v2.4.0 отвори **Settings → JSON Backup**.
2. Провери в Android **Files → Downloads**, че файлът е там. Не възстановявай архива, ако няма нужда.
3. Не деинсталирай старото MyHub, не използвай „Clear site data“ и не изтривай IndexedDB.

## Качване

1. Изтегли `MyHub-v2.5.0-UPDATE-ONLY.zip` и го разархивирай чрез приложението Files.
2. Отвори съществуващото GitHub хранилище за MyHub в Chrome. По желание активирай **Desktop site** от менюто ⋮, за да се виждат контролите.
3. Прегледай `CHANGED-FILES.txt` — там са точните имена на новите и променените файлове. Качвай всеки в **същата папка**, както е в архива. Например `js/football-second-source-core.js` отива в `js/` в GitHub.
4. Замени пълното съдържание на съществуващите файлове. Не прави частични промени по редове. Не изтривай други папки.
5. Включи `index.html`, `sw.js`, `football.css`, `js/config.js`, `js/football.js`, `js/i18n.js` и двата нови JS файла. Може да качиш и всички тестове — не се зареждат в PWA.
6. Запази промените (Commit changes) в `main`. GitHub Pages трябва да остане **Deploy from branch → main → /(root)**.
7. **Не качвай ZIP като един файл** — GitHub Pages не го разархивира автоматично. Няма нужда да създаваш допълнителна папка `MyHub-v2.5.0` в repository-то.

## Проверка в Android Chrome

1. Отвори MyHub от **съществуващата PWA икона**, после Settings → PWA и обновления → провери/обнови. Потърси **v2.5.0**.
2. Провери, че твоите Notes, Weather градове, задачи и любимите отбори са запазени.
3. Отвори **Football**. След обичайните резултати намери **„Провери резултатите от втори източник (SportScore)“** и разгъни панела.
4. Първоначално датата е вчера (UTC). Избери **събота 21.11.2026** или **неделя 22.11.2026**, ако проверяваш срещите от последния уикенд, после „Обнови“.
5. Ако срещите са много, въведи име на отбор в полето за търсене. Крайният резултат се показва само ако SportScore го е означил като завършен.
6. Сравни статуса в SportScore с OpenLigaDB. **Не се прехвърлят автоматично резултати между двата източника.** Ако SportScore не зареди, вероятно има мрежов/CORS проблем или непълни данни. Използвай съществуващото OpenLigaDB табло и ми кажи съобщението за грешка.
7. Пробвай MyHub офлайн — останалите локални инструменти трябва да работят. Вторият източник изисква интернет и не се добавя към JSON Backup.

## Защо има линк „Powered by SportScore“?

Това е **задължително видимо посочване на източника**, а не реклама или проследяващ скрипт. Без него използването на безплатния API не отговаря на условията. Има малка статична връзка в долната част на страницата и връзка в самия Football панел. Тя не изпраща личните ти бележки или настройки към доставчика.

## Какво е тествано

- 298 Node автоматизирани теста, включително всички тестове от v2.4.0 и 12 нови теста за алтернативния източник.
- Проверка на JavaScript синтаксиса и списъка на Service Worker за офлайн файлове.
- Сравнение: малкият ZIP върху базовата v2.4.0 дава същите файлове като пълния v2.5.0 ZIP.
- **Не е проверено:** действителните отговори на SportScore в Android и пълното стартиране в Chromium, защото тестовият браузър блокира локалния уеб адрес. Няма обещание за гарантирано live покритие.
