# MyHub v3.0.0 — Инструкции за Android и GitHub

Това обновление е **от v2.9.0 към v3.0.0**. Запазва всички съществуващи инструменти (включително SportScore и Weather) и добавя **постоянно кошче в Бележки**. Не са нужни компютър, Android Studio, платени услуги или нов API.

## 1. Първо защити данните

1. Отвори инсталираната MyHub v2.9.0 от досегашната икона.
2. Отвори **Settings / Настройки → JSON Backup / Изтегли JSON архив**.
3. Провери с Android **Files → Downloads**, че JSON файлът е реално изтеглен и не е празен. Запази го отделно от ZIP архива на проекта.
4. **Не деинсталирай** PWA, не избирай **Clear site data** и не променяй адреса на GitHub Pages.

## 2. Качване на v3.0.0 през телефона

1. Изтегли `MyHub-v3.0.0-UPDATE-ONLY.zip` и го разархивирай чрез Files.
2. Отвори **същото** GitHub хранилище, в което вече работи MyHub. При нужда включи Chrome → **⋮ → Desktop site**.
3. Прочети `APP-FILES-ONLY.txt` в ZIP. Това е краткият списък с кодовите файлове, които трябва да публикуваш; `CHANGED-FILES.txt` включва и тестовете/документацията.
4. За **новия** `js/notes-trash-core.js` създай файл в съществуващата папка **js** — точно до `js/notes.js` и `js/db.js`.
5. За **вече съществуващите** файлове отвори съответната папка в GitHub и замени пълното им съдържание със съдържанието от новата версия. Използвай **Edit (молив) → Select all → Paste → Commit changes**. Ако GitHub позволява качване/замяна на файлове през браузъра, може и **Add file → Upload files** в съответната папка.
6. **Не качвай ZIP файла като ZIP**, не поставяй файловете в допълнителна папка `MyHub-v3.0.0` и не изтривай други JavaScript модули.
7. Увери се, че **sw.js** е заменен — той включва новия модул в офлайн кеша.
8. След GitHub Pages публикацията отвори MyHub → **Настройки → PWA и обновления → Провери за обновление**. Ако има чакаща версия, избери **Обнови**.
9. **Настройки → Версия** трябва да показва **3.0.0**. Не е нужна нова инсталация.

## 3. Безопасен тест с пробна бележка

1. Отвори **Бележки** и създай тестов checklist „Проба кошче“ с два реда; маркирай единия като готов.
2. Закрепи бележката и я маркирай като любима. Върни се в списъка, за да приключи запазването.
3. Отвори я, натисни **Изтрий → Премести в кошчето**.
4. В списъка натисни **Кошче**. Трябва да виждаш тестовата бележка. Няма нужда да използваш временния бутон „Върни“.
5. Затвори **напълно** MyHub и отвори пак от инсталираната PWA икона. Отвори **Бележки → Кошче**. Тестовата бележка трябва да е там.
6. Натисни **Възстанови**. Провери, че бележката се е върнала в списъка, със същите checklist отметки, закрепване и любима звезда.
7. Създай втора тестова бележка, премести я в Кошчето и пробвай **Изтрий окончателно** само върху нея. Тази операция не може да се отмени без предишен JSON архив.
8. Направи **нов JSON Backup**. При Restore избери файла и прегледай сравнението, но натисни **Отказ**, без да заместваш данните за тест.

## 4. Как работи защитата

- Кошчето пази до **100 бележки** и **не изтрива нищо автоматично**. Когато се запълни, MyHub няма да изтрие нова бележка, докато не освободиш място съзнателно.
- Изтриване и възстановяване са една атомарна операция в IndexedDB: при грешка не трябва да остане половин запис.
- При конфликт от друг таб MyHub отказва рисковото действие. Можеш да отвориш Notes отново, за да заредиш последните данни.
- В кошчето се пази пълно копие на бележката. Това използва локално пространство в телефона; browser Site Data изтриване премахва и него.
- JSON Backup на v3.0.0 включва кошчето. **Стар архив от v2.9.0 или по-рано няма кошче**; ако го възстановиш, текущите изтрити бележки ще бъдат заменени с празно кошче. Затова първо архивирай текущата v3.0.0.
- **Изтрий окончателно** и **Изпразни кошчето** са необратими без по-стар архив.

## 5. Проверка на другите инструменти

Отвори Weather, Football → SportScore → Premier League, Calendar и Tasks. Техните файлове и настройки не са променяни в това обновление. Ако видиш стар интерфейс, провери **PWA и обновления** и правилните пътища на GitHub файловете, без деинсталация.

## 6. Ако възникне проблем

- **Версията остава 2.9.0:** провери `sw.js`, `js/config.js` и дали GitHub Pages вече е публикувал промените. От настройките активирай предложената версия.
- **Бележки не се отварят:** провери новия път `js/notes-trash-core.js` и че `js/db.js`, `js/notes.js`, `js/i18n.js` са публикувани.
- **Кошчето показва повреда:** не използвай Restore/Empty Trash за експерименти и не изчиствай Site Data. Запази наличните JSON архиви и изпрати точния текст на грешката.
- **Възстановяване отказано:** възможно е ID конфликт или достигнат лимит за Notes. Не изтривай важни бележки, за да го поправиш на сляпо.

Във версията няма платени API, фонова синхронизация, акаунти, реклами или излишни разрешения.
