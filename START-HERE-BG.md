# MyHub v3.1.0 — инструкции за Android + GitHub

Тази версия надгражда **v3.0.0 → v3.1.0**. Работи като съществуваща PWA; няма нужда от APK, компютър, сървър или платени услуги.

## 1. Преди обновяване: архивиране

1. Отвори съществуващата MyHub **v3.0.0** от иконата на Android.
2. Влез в **Настройки → JSON Backup → Изтегли**.
3. Провери в **Files → Downloads**, че JSON файлът действително присъства и не е празен. Запази го на безопасно място.
4. **Не деинсталирай MyHub, не избирай Clear site data и не сменяй GitHub Pages адреса.**

## 2. Публикуване от телефона

1. Изтегли `MyHub-v3.1.0-UPDATE-ONLY.zip` и го разархивирай с Android Files.
2. Отвори същото GitHub хранилище. В Chrome можеш да включиш **⋮ → Desktop site**, ако е необходимо.
3. Отвори `APP-FILES-ONLY.txt` в архива. Това са всички файлове, необходими на самото приложение — не е нужно да качваш тестовете, за да работи PWA.
4. В папката `js` създай двата **нови** файла `notes-category-core.js` и `weather-day-compare-core.js`. Постави ги до останалите `.js` файлове, а не в допълнителна подпапка.
5. Замени **пълното съдържание** на останалите файлове от `APP-FILES-ONLY.txt`. В GitHub отвори файла → Edit (молив) → Select all → Paste → Commit changes; или използвай Upload files в съответната папка, когато е удобно.
6. Увери се, че `sw.js`, `js/config.js`, `js/db.js`, `js/notes.js` и `js/weather.js` са обновени. **Не качвай ZIP като единичен файл** и не изтривай работещите модули.
7. След публикуването през GitHub Pages отвори PWA → **Настройки → PWA и обновления → Провери за обновление**; активирай предложената версия.
8. Провери **Настройки → Версия 3.1.0**. Може да се наложи да затвориш и отвориш отново приложението.

## 3. Безопасна проверка на Notes

1. Отвори **Бележки** → създай пробна бележка „Тест категории“.
2. В полето **Категория** въведи „Лични“; върни се към списъка и изчакай да се запази.
3. В списъка трябва да се появи филтър **Категория**. Избери „Лични“, после „Без категория“ и „Всички категории“.
4. Отвори бележката, натисни **Дублирай** и провери, че новото копие е в категория „Лични“.
5. Премести копието в **Кошче**, затвори и отвори отново MyHub, върни го чрез „Възстанови“ и провери категорията.
6. Провери, че старите ти бележки без категория все още се отварят, а Football и другите инструменти работят.

## 4. Проверка на Weather

1. Свържи телефона с интернет и отвори **Времето** за някой от запазените градове.
2. Натисни **Обнови**, за да получиш новите до 48 почасови стойности.
3. Под резюмето за дъжд потърси панелите **Днес** и **Утре**. Натисни върху всеки, за да разгънеш местните часове и вероятността за валежи.
4. Изключи интернета и отвори отново Weather. Последният получен кеш трябва да остане видим, обозначен с часа на обновяване.
5. Старият 12-часов кеш е валиден, но може да няма часове за утре, докато не обновиш прогнозата онлайн.

## 5. Проверка на Backup без изтриване

1. Създай нов JSON Backup с категорията и обновената прогноза.
2. От Settings избери Restore и този JSON файл; **само разгледай прегледа**, след което натисни **Отказ**.
3. Не възстановявай стар архив само за тест: Restore замества сегашните записи, включително Notes Trash.

## 6. Ако нещо не работи

- **Версия 3.0.0 остава:** провери публикацията в GitHub Pages, `sw.js` и `js/config.js`, после PWA → Провери за обновление. Не деинсталирай.
- **Notes не се отварят:** провери точно `js/notes-category-core.js`, `js/notes-view-core.js`, `js/notes-trash-core.js`, `js/notes.js` и `js/db.js`.
- **Времето не зарежда:** провери `js/weather-day-compare-core.js`, `js/weather.js`, `js/db.js`, `sw.js` и връзката с интернет. Без данни за утре? Натисни „Обнови“.
- **Грешка с архив:** не презаписвай или изтривай данните. Запази стария JSON и изпрати точния текст на грешката.
- **Само интерфейсът е остарял:** не изтривай кеша на сайта на сляпо; в Настройки провери състоянието на Service Worker и активирай обновлението.

Тестове: **346 от 346 автоматизирани проверки успешни**. Пълната PWA в Android Chrome трябва да се потвърди след публикуване. За допълнителни подробности виж `README.md`.
