# MyHub v2.9.0 — обновяване само с Android и GitHub

Надгражда **v2.8.0**. Ако на телефона се вижда друга версия, първо уточни текущата версия — малкият ZIP е предназначен за v2.8.0. За изцяло нова инсталация използвай пълния архив.

## 1. Безопасен архив

1. Отвори сегашния MyHub **v2.8.0** от досегашната икона на Android.
2. Settings → **JSON Backup**. Изтегли файл.
3. Провери във **Files → Downloads**, че JSON файлът наистина е наличен и не е с нулев размер. Запази и по-старите архиви.
4. **Не деинсталирай PWA, не използвай Clear site data и не възстановявай архив върху реалните данни само за тест.**

## 2. Качване на променените файлове

1. Изтегли `MyHub-v2.9.0-UPDATE-ONLY.zip` и го разархивирай с Files на Android.
2. Отвори **същото** GitHub хранилище като преди. При нужда използвай **Chrome → Desktop site**.
3. В архива има `CHANGED-FILES.txt` (всички промени) и **`APP-FILES-ONLY.txt`** — по-кратък списък, достатъчен за работещата PWA в GitHub Pages. Тестовете могат да се качат по-късно, но препоръчвам да запазиш и тях в проекта.
4. За съществуващ файл отвори пътя му в GitHub, избери **Edit (икона молив)**, изтрий старото съдържание и постави **цялото съдържание** на новия файл. Избери **Commit changes**. Ако позволява, използвай Add file → Upload files за няколко файла в същата папка.
5. Новият файл `js/weather-hour-core.js` трябва да попадне **директно в папката `js/`**, до останалите JavaScript файлове. **Не качвай ZIP файла като ZIP в GitHub** и не създавай директория `MyHub-v2.9.0` около проекта.
6. Остави всички останали файлове и особено `js/football*.js` на местата им. Тази версия **не променя SportScore**.
7. Провери в GitHub, че файлът `sw.js` е обновен. Ако той липсва или е стар, кешът може да задържа старата версия.
8. Когато GitHub Pages публикува промените, отвори MyHub → Settings → **PWA и обновления** → провери за актуализация. Ако приложението предложи обновяване, активирай го. Не изтривай данните на сайта.
9. Settings → Version трябва да показва **2.9.0**.

## 3. Проверка на Notes без риск за старите бележки

1. Отвори Notes. Създай **нова тестова бележка**, например „Тест Undo“, и добави един-два реда. Върни се в списъка, за да се запише.
2. Отвори само тестовата бележка → Delete → потвърди. В списъка трябва да се появи **„Върни“**.
3. Натисни „Върни“: тестовата бележка трябва да се възстанови със същия текст.
4. За проба с checklist можеш да създадеш втори тестов списък, да маркираш един ред и да провериш дали отметката се запазва след изтриване и Undo.
5. **Важно:** Това е еднократно Undo само докато Notes остава отворен. Няма Trash, и не трябва да изпробваш възстановяване с важни бележки.

## 4. Проверка на Weather

1. Отвори Weather → избери Newport или друг запазен град.
2. При интернет използвай „Обнови“ и намери **почасовата прогноза** под прогнозата по дни.
3. Всяка часова карта трябва да има процент за вероятност за валежи и малка лента под него. Колкото по-висок е процентът, толкова по-дълга е лентата. Ако липсва процент, се показва „–“, не 0%.
4. Отвори MyHub офлайн след като веднъж си заредил прогноза. Последно запазените почасови данни и ленти трябва да се виждат, с информация за актуалността.
5. Процентът е вероятност, а не сигурна прогноза за дъжд.

## 5. Бърза проверка на останалото

- Отвори Football → SportScore → English Premier League. Данните и фаворитите трябва да останат както във v2.8.0.
- Провери една съществуваща задача и календарно събитие; нищо не трябва да липсва.
- Отвори Settings и провери JSON Backup, без да правиш Restore.

## Ако нещо не работи

- Ако виждаш старата версия, първо **Settings → PWA и обновления**, а не деинсталация.
- Ако даден нов файл не се намира, провери дали си го качил в правилната GitHub папка.
- Ако Undo показва грешка, изпрати ми точния текст. Възможно е друг таб да е променил записа; MyHub отказва да презапише конфликтните данни.
- Ако видиш бял екран, провери дали всички файлове от `APP-FILES-ONLY.txt` са публикувани, особено `sw.js` и `js/weather-hour-core.js`.

Архивирането и обновяването са изцяло безплатни; не се изискват компютър, Android Studio или платени API.
