# MyHub v0.1.0 — инструкции само с Android телефон и GitHub

## Какво получавате

Готово PWA приложение с: начален екран, любими инструменти (избор и пренареждане), калкулатор с проценти и история, световен часовник, бележки и списъци, български/английски, настройки и JSON Backup / Restore. Не е нужен компютър, npm, сървър или API ключ.

## Стъпка 1: Подгответе GitHub

1. Отворете Chrome на телефона и влезте в [github.com](https://github.com/).
2. Отворете `https://github.com/new`.
3. Напишете име на хранилището **myhub**.
4. Изберете **Public** (за безплатен GitHub Pages). НЕ избирайте допълнителен README или `.gitignore`, защото файловете вече ги има в архива.
5. Натиснете **Create repository**.

## Стъпка 2: Качете файловете

1. Изтеглете ZIP архива с проекта и го разархивирайте чрез приложението **Files / Файлове** на Android.
2. Влезте в новото хранилище `myhub` на GitHub. При необходимост включете **Chrome → ⋮ → Desktop site (Версия за компютър)**.
3. **Add file → Upload files**: качете от извлечената папка кореновите файлове: `index.html`, `styles.css`, `sw.js`, `manifest.webmanifest`, `README.md`, `START-HERE-BG.md`, `package.json`, `.nojekyll`. Изберете **Commit changes**. Ако Android не показва скрития `.nojekyll`, може да го пропуснете.
4. Ако папката `js` не съществува, използвайте **Add file → Create new file** с име `js/.gitkeep` и **Commit**. Отворете папката `js` на GitHub и там чрез **Add file → Upload files** качете **всичките 8 .js файла** от папка `js` в телефона; **Commit**.
5. По същия начин създайте папка `icons` чрез `icons/.gitkeep`. Влезте в нея и качете трите `.png` иконки от папка `icons`; **Commit**.
6. По същия начин създайте папка `tests` чрез `tests/.gitkeep`. Качете файла `smoke.test.mjs` там; **Commit**. Тази папка не е необходима за работа на приложението, но е препоръчителна за бъдещи проверки.
7. **Важно:** Не качвайте просто ZIP файла в GitHub и не очаквайте GitHub автоматично да го разархивира. Трябва да са качени отделните файлове с правилната структура.

Проверете дали коренът на хранилището съдържа `index.html`, `sw.js`, `styles.css`, `manifest.webmanifest` и папки `js`, `icons`, `tests`. Не поставяйте всичко в допълнителна папка `MyHub-v0.1.0` вътре в хранилището.

## Стъпка 3: Активирайте GitHub Pages

1. Отворете **Settings** на хранилището (може да трябва Desktop site).
2. Изберете **Pages**.
3. В **Build and deployment** изберете **Deploy from a branch**.
4. Изберете **Branch: main**, папка **/(root)** и натиснете **Save**.
5. Отворете: `https://ВАШЕТО-GITHUB-ИМЕ.github.io/myhub/`.
6. Ако сайтът все още не се показва, проверете **Actions / Pages** за публикуването и опитайте отново след него.

## Стъпка 4: Инсталирайте на Android

1. Отворете горния адрес в **Android Chrome**.
2. Изчакайте началният екран да се зареди.
3. Натиснете **⋮** в Chrome → **Add to Home screen / Добавяне към началния екран** → **Install / Инсталиране**, ако е налично.
4. Стартирайте MyHub от новата икона. Самостоятелните инструменти ще работят без интернет след първото успешно зареждане.

## Стъпка 5: Проверки

1. **Калкулатор:** въведете `200+10%`, натиснете `=` и трябва да получите `220`.
2. **Бележки:** създайте бележка, напишете текст, изчакайте да пише **Запазено локално**, затворете и отворете приложението. Бележката трябва да е там.
3. **Световен часовник:** добавете Токио, затворете/отворете приложението — градът трябва да остане.
4. **Настройки:** изберете тъмна тема, сменете езика и пренаредете любимите инструменти. Проверете дали промените остават след повторно отваряне.
5. **Архив:** Settings → **Изтегли JSON архив**. Пазете файла на сигурно място.
6. **Офлайн:** след успешна инсталация и пълно онлайн зареждане, включете самолетен режим и отворете приложението пак.

## Много важно за данните

- Бележките и настройките **не се качват в GitHub**. Те остават в IndexedDB на браузъра.
- Ако изтриете данните на сайта, браузъра или PWA, може да загубите информацията. Използвайте **Settings → Изтегли JSON архив** редовно.
- **Възстановяването замества всички текущи данни** с тези от архива, след проверка на файла и ваше потвърждение. Първо запазете нов архив.
- Когато някой ден направим APK, данните няма да се появят там автоматично. Ще направите **Export JSON** от PWA и **Import JSON** в APK.
- Не променяйте името/пътя `myhub` след започване на работа, без предварително архивиране: новият адрес има отделно браузърно хранилище.
