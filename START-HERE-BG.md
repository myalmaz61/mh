# MyHub v0.2.0 — инструкции за Android + GitHub

Тази версия добавя реален модул **Времето (Weather)** към MyHub v0.1.0. Не трябва да започваш отначало, да инсталираш Android Studio или да плащаш за услуги.

## A. Ако вече имаш MyHub v0.1.0

### 1. Направи архив ПРЕДИ обновяването

1. Отвори инсталирания MyHub.
2. Отвори **Настройки → Изтегли JSON архив**.
3. Провери в „Изтегляния/Downloads“, че файлът `MyHub-backup-...json` е наличен. Запази копие на безопасно място.
4. **Не изтривай** приложението и **не използвай** Chrome → Clear site data / Clear storage.

### 2. Изтегли файловете

Използвай **MyHub-v0.2.0-UPDATE-ONLY.zip**: съдържа само новите и променени файлове (всички са пълни, не са откъси). Пълният ZIP е удобен за ново инсталиране или ако ти трябва пълно копие на проекта.

Разархивирай ZIP на Android чрез Files / My Files. ZIP не може просто да се качи като един файл в GitHub — GitHub Pages няма да го разархивира.

### 3. Обнови хранилището в GitHub

Отвори **същото** GitHub хранилище, в което е публикувана v0.1.0. Например `https://github.com/ТВОЯ-ПРОФИЛ/myhub`.

Файловете, които трябва да се качат/заменят, са:

**В основната папка (root):**

- `index.html` — замени целия стар файл.
- `weather.css` — нов файл.
- `sw.js` — замени стария Service Worker.
- `package.json` — замени (версията за тестовете; не е необходим, за да работи PWA).
- `README.md` — замени (документация).
- `START-HERE-BG.md` — замени (тази инструкция).

**В папката `js`:**

- `app.js` — замени.
- `config.js` — замени.
- `db.js` — замени.
- `i18n.js` — замени.
- `weather.js` — нов файл.

**В папката `tests`:**

- `smoke.test.mjs` — замени.
- `weather.test.mjs` — нов файл.

Не променяй останалите файлове: `styles.css`, `js/calculator.js`, `js/notes.js`, `js/world-clock.js`, `js/utils.js`, `manifest.webmanifest`, трите PNG икони и `.nojekyll`.

### 4. Практично качване само от Android

1. Отвори хранилището в **Chrome**. Ако няма бутони за качване, меню **⋮ → Desktop site**.
2. В основната папка използвай **Add file → Upload files**. Избери нужните файлове от разархивираната папка, като не смесваш файловете от `js` и `tests` с кореновите файлове.
3. Потвърди/замени файловете със същите имена, ако GitHub поиска, след което **Commit changes**.
4. Отвори папка **js** в GitHub и качи петте посочени `.js` файла, като замениш съществуващите. Commit.
5. Отвори папка **tests**, качи двата `.mjs` файла. Commit.
6. В GitHub провери дали `weather.css` се намира **до** `index.html`, а `weather.js` е вътре в **js**. Нито един от тях не бива да е в допълнителна вложена папка `MyHub-v0.2.0`.

Ако GitHub не позволява да замениш даден файл чрез Upload: отвори файла в GitHub → **иконата на молив (Edit)** → **Select all** → постави ПЪЛНИЯ код от `MyHub-v0.2.0-FULL-SOURCE.md` → **Commit changes**. Не трябва да променяш отделни редове.

### 5. Отвори обновената PWA

1. GitHub Pages ще публикува новите файлове от същото хранилище (не е нужно да създаваш второ).
2. Отвори същия URL на MyHub в Android Chrome или от съществуващата PWA и провери **Настройки → Версия**.
3. Ако се появи „Налична е нова версия → Обнови“, натисни **Обнови** и отвори приложението отново.
4. Очаквана версия: **v0.2.0**. Ако още показва v0.1.0, отвори сайта в Chrome, обнови страницата и стартирай пак PWA. **Не изтривай данните на сайта**.

## Б. Как да използваш Weather

1. Отвори **Инструменти → Времето**. По подразбиране е добавен **Newport, Shropshire, United Kingdom**. Това е избрано населено място, не автоматично засечено GPS местоположение.
2. При интернет достъп прогнозата се зарежда от Open-Meteo.
3. За нов град напиши например `Sofia`, `Istanbul` или `Newport`, натисни **Търси** и избери правилния град от списъка с държава/област. Може да добавиш до осем града.
4. От падащото меню сменяй градовете; бутонът **Обнови** иска нова прогноза.
5. Ще виждаш текуща температура, усещане, влажност, вятър, текущи валежи, седемдневна прогноза и часове с вероятност за дъжд.
6. **Настройки → Любими инструменти → Времето**, ако искаш бутон за прогнозата на началния екран. По подразбиране началният екран остава изчистен.
7. След като веднъж си отворил прогнозата успешно, ще можеш да я виждаш и без интернет. Ще има дата и час на последното зареждане. Това **не е нова** прогноза, докато си офлайн.

Свежи данни и търсене на нови градове изискват интернет. Прогнозата не е официално предупреждение за опасно време. Приложението няма реклами, регистрирани акаунти или ключове за платени API.

## В. Проверка след обновяване (5–10 минути)

- [ ] **Настройки** показват v0.2.0, а предишният избор на тема и любими инструменти е запазен.
- [ ] Старите **Бележки** и Checklist записи са налични.
- [ ] Старите изчисления и градовете от **Световен часовник** са налични.
- [ ] **Времето** показва Newport, Shropshire — не Newport в Wales.
- [ ] Добави например Sofia и превключи между двата града.
- [ ] Затвори и отвори MyHub отново: изборът на град трябва да остане.
- [ ] Изключи интернета временно и отвори **Времето**: показва последната успешно заредена прогноза, ако вече има такава.
- [ ] Включи интернета и натисни **Обнови**.
- [ ] Изтегли **нов JSON архив** и потвърди, че файлът е създаден. За пробно възстановяване първо запази текущите данни и помни, че restore **ЗАМЕНЯ**, не обединява.

## Г. Ако започваш от нулата

1. Създай **public** хранилище `myhub` на https://github.com/new (без да добавяш стартов README).
2. Разархивирай `MyHub-v0.2.0.zip` в телефона.
3. Качи съдържанието на папката в root и правилните подпапки `js`, `icons`, `tests`.
4. В GitHub отвори **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
5. Отвори `https://ТВОЯ-ПРОФИЛ.github.io/myhub/` и инсталирай от Chrome **⋮ → Add to Home screen → Install** (ако опцията е налична).

## Д. Сигурност и данни

- Запазваме същата IndexedDB база: `myhub-local` версия **1**. Обновяването на файловете и Service Worker не изтрива базата.
- JSON архивите от **v0.1.0 остават съвместими**. Новите архиви включват и прогнозите.
- Възстановяване: проверка на архива → твоето потвърждение → атомично заместване. Ако операциите не успеят, транзакцията трябва да се върне назад.
- Ако смениш GitHub Pages адреса, браузърът може да третира приложението като ново местоположение. Използвай Export JSON / Import JSON за прехвърляне.
- Бъдещ Android APK с Capacitor няма автоматично да наследи данните от PWA. Ще ги прехвърляме с JSON архив.
- Open-Meteo API е безплатен за нетърговска употреба според текущите условия, но няма обещание за постоянна наличност. Данни и лиценз: https://open-meteo.com/ и CC BY 4.0.
