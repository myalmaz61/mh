# MyHub — Personal Tools v2.7.0

## Защо тази версия?

В v2.6.0 SportScore показваше празен списък дори когато на страницата на английската Premier League има приключили срещи. Два вероятни проблема:

1. Приложението изпращаше `competition=premier-league`, но реалната страница е с път `english-premier-league`. Това **може** да е неправилен API идентификатор.
2. Локалният филтър отхвърляше някои варианти на името, например `English Premier League 2026/27`, дори ако отговорът съдържа мачове.

### Какво е променено
- Първо се опитва `competition=english-premier-league`.
- Ако не намери срещи, проверява алтернативно идентификатора на страницата `jednm9whz0ryox8`.
- Последният опит проверява общия дневен списък, но показва само мачове с потвърдено съответствие с английската Premier League. Този списък е ограничен до 200 мача по API и може да пропусне търсеното първенство.
- По-гъвкаво, но предпазливо разчитане на имена на първенства, включително имена със сезон.
- **Football → SportScore → Диагностика на заявките** показва HTTP статус, броя получени записи и колко са разчетени като EPL.
- **Отвори API отговора в Chrome** е помощна връзка за проверка на точната заявка.
- **OpenLigaDB, фаворитите, кешовете и останалите модули не са променени.**

**Важно:** Отделната уебстраница и публичният API не са гарантирано еднакви. Нямаме успешно потвърден истински API отговор от работната среда. Не показваме фиктивни мачове. Ако всички опити върнат 0 или грешка, ще видиш причините в диагностиката и ще можеш да ползваш директната SportScore страница.

## Инсталация

Виж `START-HERE-BG.md`. За обновяване на работещо v2.6.0 използвай `MyHub-v2.7.0-UPDATE-ONLY.zip`. Вземи JSON Backup преди всяка актуализация и не деинсталирай PWA.

## Архитектура

- Безплатна PWA, GitHub Pages, само Android.
- Локално IndexedDB `myhub-local`, версия 1; JSON Backup формат 1.
- Няма нови разрешения, регистрации, платени API или сървър.
- Версия 2.7.0; офлайн пакет `myhub-shell-v2.7.0`.
- Автоматизирани тестове: `npm test` (Node.js на CI или компютър, не е необходим за Android инсталацията).
