# MyHub v1.1.0 — Quick Add

Безплатно local-first PWA за Android Chrome и GitHub Pages. Версията надгражда **MyHub v1.0.0**, без преинсталация.

## Ново

- Бутон **+** долу вдясно само на екраните **Начало** и **Инструменти**.
- Добавяне на **Задача** със заглавие, незадължителни подробности, срок и висок приоритет.
- Добавяне на **Бележка** със заглавие и незадължителен текст.
- След успешен запис се отваря създадената задача или бележка за редактиране.
- Проверка за празно/невалидно заглавие, достигнат лимит и повредени данни.
- За новите задачи е използвана **единна IndexedDB readwrite транзакция**, която извършва прочит, проверка и добавяне на запис в една операция, вместо да презаписва старо копие на списъка.
- Без нови разрешения, API, cloud услуги или ново хранилище.

## Данни

- IndexedDB **`myhub-local`**, версия **1**, остава непроменена.
- Задачите използват съществуващия `meta.tasksData`, бележките използват `notes`.
- JSON Backup/Restore от v1.0.0 продължава да работи и включва записите, създадени чрез Quick Add. Няма нужда от миграция.
- При неуспешен запис прозорецът остава отворен с въведения текст.
- При затваряне с незаписан текст приложението иска потвърждение.

## Тестове

Без външни пакети, с инсталиран Node.js: `npm test`.

- Всички **112 автоматизирани теста** са успешни в работната среда.
- Изолираният Quick Add интерфейс е проверен в Chromium за задача, бележка, срок, приоритет, навигация и показване на бутона.
- Не е изпълнен пълен енд-ту-енд тест на цялата PWA в Android Chrome: тестовата среда блокира HTTP достъпа до localhost. Проверете на физическото устройство след публикуване.

## Инсталация

Пълни инструкции: [START-HERE-BG.md](START-HERE-BG.md).

## Ограничения

Quick Add не изпраща известия и не създава системни Android аларми. Не е интегриран с Android Share Sheet — това е отделна планирана функция.
