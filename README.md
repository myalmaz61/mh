# MyHub v1.6.0 — Подредба на всички инструменти / All Tools Sorting

Това е **работеща надстройка от v1.5.0**, а не ново приложение. Използва същия GitHub Pages адрес и същата локална IndexedDB база.

## Какво ново

В **Настройки → Подредба на всички инструменти** има сгъваем списък с всичките 16 инструмента. Премествай всеки с големите бутони **↑ / ↓**. В „Всички инструменти“ редът се променя веднага след запазване. Бутон **„Върни стандартната подредба“** връща първоначалния ред.

- Подредбата важи само за основния списък „Всички инструменти“. **Любимите** на началния екран и **Последно използваните** запазват самостоятелната си логика.
- Скритите инструменти също са в списъка за подреждане и са обозначени като „Скрит“. При повторно показване се връщат на запазеното място.
- Няма нови инструменти, разрешения, акаунти, платени API или хостинг зависимости.
- Интерфейсът остава на български / английски; началният екран е непроменен.

## Защита на данните

- IndexedDB **`myhub-local` версия 1** е непроменена, без нови object stores.
- `settings.toolOrder` записва само реда на IDs. Не променя Notes, Calendar, Tasks, Weather, Football, RSS, Bookmarks, таймер или лични записи.
- Старите настройки без `toolOrder` получават досегашната стандартна подредба.
- **JSON Backup `format: 1`** вече включва `toolOrder`. Архиви от v0.1–v1.5 остават съвместими. Невалидна подредба в нов архив се отхвърля при проверката преди Restore.
- При бъдещо добавяне на нов инструмент старият ред може да се възстанови; новите ID-та се поставят след вече подредените.
- **Restore заменя текущите данни**. Преди такова действие винаги прави актуален JSON Backup и провери изтегления файл.
