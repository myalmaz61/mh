# MyHub — Personal Tools v2.8.0

## За тази версия

Тази версия подобрява **Notes** и **Weather**. Не добавя инструменти, не променя началния екран и **не променя Football, включително работещия SportScore от v2.7.0**.

### Notes — по-лесна работа

- В списъка има компактни филтри **Всички / Закрепени / Любими**.
- Сортиране: **Последно променени / Най-стари / По заглавие**. Закрепените бележки винаги са първи.
- Показва се колко бележки съответстват на избрания филтър. Търсенето проверява и редовете в checklist.
- В редактора има **Сподели**: използва системното Android Share меню, ако е налично; иначе се опитва да копира текста. При отказ от Share не изпраща нищо.
- Филтрите са временен избор за текущото отваряне на Notes; те не променят бележките и не се добавят като настройки.

### Weather — час с по-висок шанс за дъжд

- Използва последните до 12 запазени почасови прогнози от Open-Meteo.
- Показва **първия час, когато вероятността за валежи е поне 50%**, с местната дата и час за избрания град.
- Ако в наличните часове няма стойност поне 50%, съобщава това предпазливо — не твърди, че няма да вали.
- Не добавя нови заявки, API ключ, акаунт или допълнителни лични данни. Работи със запазена прогноза офлайн, с вече наличното обозначение дали кешът е стар.

## Защита на данните и съвместимост

- IndexedDB: **`myhub-local`, версия 1** — не се променя.
- JSON Backup: **формат 1**, както преди. Старите архиви остават съвместими.
- Без миграция, изтриване, скрити автоматични промени или платени услуги.
- Offline shell cache: `myhub-shell-v2.8.0`; включва `js/notes-view-core.js`.
- SportScore API, OpenLigaDB, RSS, Tasks, Calendar и останалите модули остават непроменени (освен обновяване на тестовите очаквания за версията).

## Проверки

`npm test` — **315 успешни автоматизирани теста**, включително новите тестове за Notes филтри и Weather прогнозата. Проверени са JavaScript синтаксисът, ресурсите на Service Worker, и идентичността на пълния ZIP и приложеното обновление върху v2.7.0.
